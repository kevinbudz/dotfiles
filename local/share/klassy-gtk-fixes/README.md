# Klassy GTK Fixes

This fixes the mismatch between Klassy window decorations and GTK CSD (Firefox, etc.)
for icon sizing, hover behavior and spacing.

## What was changed

### 1. `~/.config/gtk-3.0/window_decorations.css` and `~/.config/gtk-4.0/window_decorations.css`
- Kept original `background-image` mappings for close/minimize/maximize (generated by kde-gtk-config)
- Added overrides to match your Klassy settings:
  - `ButtonIconStyle=Material`, `ButtonShape=FullHeightRectangle`, `IconSize=Medium`
  - `TitleSidePadding=8`, `TitleBarTop/BottomMargin=5`
  - `FullHeightButtonWidthMarginLeft=8, Right=18, CloseRelative 110%`
  - `FullHeightButtonSpacing 2/4`

Key CSS added:
```css
headerbar, .titlebar {
  min-height: 30px;
  padding-left: 8px;
  padding-right: 8px;
}
headerbar button.titlebutton,
.titlebar button.titlebutton {
  min-width: 32px;
  min-height: 24px;
  background-size: 18px 18px; /* IconSize Medium = 18 */
  border-radius: 6px;
  transition: all 150ms ease-in-out;
}
headerbar button.titlebutton.close { min-width: 35px; } /* 110% wider */
headerbar button.titlebutton + button.titlebutton { margin-left: 4px; } /* ButtonSpacing */
```

This makes:
- **Icon sizing**: 18px icons in 32x24px buttons (was 18px in 18px + Breeze's 46px headerbar)
- **Spacing**: 4px between buttons + 8px side padding (was 0-6px)
- **Hover**: 150ms smooth transition, no extra shadows, relies on SVG hover images (was instant, with shadows)

### 2. `~/.config/gtk-3.0/assets/*.svg` -> `~/.config/gtk-4.0/assets/`
Copied 24 SVG button images so GTK4 apps also show Klassy icons (GTK4 assets folder was empty).

### 3. `~/.config/gtk-3.0/gtk.css` and `gtk-4.0/gtk.css`
Fixed duplicate `@import 'colors.css';@import 'colors.css';` bug (now single import).

### 4. Persistence
- Fixed source SCSS at `/tmp/kde-gtk-src/kde-gtk-config/kded/scss/window_decorations.scss` (built to 5.5K via `npx sass`)
- Installed fixed CSS to `~/.local/share/klassy-gtk-fixes/window_decorations.css`
- `~/.local/bin/klassy-gtk-fix.sh` re-applies fixes if kde-gtk-config overwrites them
- Autostart desktop entry + systemd path watcher ensures fixes survive theme changes

## Tweaking

Edit `~/.config/gtk-3.0/window_decorations.css` (and copy to gtk-4.0):

- **Icon size**: change `background-size: 18px 18px;` to `16px`, `20px`, etc.
  - Tiny=8, VerySmall=12, Small=14, SmallMedium=16, Medium=18, LargeMedium=20, Large=22, VeryLarge=24, Giant=32, Humongous=48
- **Button width**: `min-width: 32px;` (try 20px for Small, 32-38px for FullHeight)
- **Button height**: `min-height: 24px;` (try 20px for Small, 24-30px for FullHeight)
- **Spacing**: `margin-left: 4px;` (change to 6px or 10px if you use Chroma preset)
- **Headerbar height**: `min-height: 30px;` (Klassy borderTop ~31px, Breeze default 46px)
- **Corner radius**: `border-radius: 6px;` (use `0` for FullHeightRectangle, `9999px` for SmallCircle)

After editing, run:
```bash
cp ~/.config/gtk-3.0/window_decorations.css ~/.config/gtk-4.0/window_decorations.css
cp ~/.config/gtk-3.0/assets/*.svg ~/.config/gtk-4.0/assets/ 2>/dev/null
# Trigger reload (module watches file)
touch ~/.config/gtk-3.0/window_decorations.css
```

## Testing

- **GTK3 preview**: `/usr/lib/gtk3_preview` should show headerbar with new sizing
- **Firefox**: Restart Firefox (`firefox --new-window about:blank` then close old). Titlebar buttons should be larger, spaced 4px, hover shows Klassy background with smooth fade.

## If kde-gtk-config overwrites

The systemd path watcher will auto-restore. You can also manually run:
```bash
~/.local/bin/klassy-gtk-fix.sh
```

## Reverting

```bash
cp ~/.config/gtk-3.0/window_decorations.css.bak.* ~/.config/gtk-3.0/window_decorations.css
cp ~/.config/gtk-4.0/window_decorations.css.bak.* ~/.config/gtk-4.0/window_decorations.css
systemctl --user disable klassy-gtk-fix.path
rm ~/.config/autostart/klassy-gtk-fix.desktop
```

## Upstream fix (optional, requires sudo)

To make the fix survive `pacman -Syu` overwriting `/usr/share/themes/Breeze/window_decorations.css`:
```bash
sudo cp ~/.local/share/klassy-gtk-fixes/window_decorations.css /usr/share/themes/Breeze/window_decorations.css
```
And to make kde-gtk-config generate correct SVGs for FullHeight (currently forces Small), patch `klassy/kdecoration/breezebutton.cpp`:
- Remove `|| m_isGtkCsdButton` from lines 189/228/258 so FullHeight is painted for GTK too,
- Rebuild Klassy: `cd ~/klassy/build && make -j$(nproc) && sudo make install`
